# Script Analysis Review Skill — 剧本结构审核

## 用途

对导演分析结果进行剧本结构审核，确保人物清单和场景清单的完整性和准确性。

---

## 审核维度

### 人物清单审核

- [ ] 主角有完整的外貌描述（年龄/体型/发型/服装）
- [ ] 配角外貌描述足够生成参考图
- [ ] 没有遗漏出场 2 次以上的重要角色
- [ ] 没有把群演列入人物清单
- [ ] 没有外貌描述自相矛盾的情况

### 场景清单审核

- [ ] 每个场景都有光线方向和色温
- [ ] 场景名称区分内景/外景
- [ ] 出场次数≥2的场景都已列入
- [ ] 没有遗漏关键道具
- [ ] 时间（白天/夜晚）有明确标注

### 讲戏本审核

- [ ] 每个镜头有建议时长
- [ ] 动作链连续（无跳跃）
- [ ] 光影描述具体（有方向和色温）
- [ ] 情绪通过视觉细节传达，无抽象描述

---
