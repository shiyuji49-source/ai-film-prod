# Compliance Review Skill — 内容合规审核

## 用途

对生成的提示词和视频内容进行合规审核，确保符合平台规定和法律要求。

---

## 审核范围

### 提示词合规

- 无暴力/血腥描述（打斗可以，但不能描述身体伤害细节）
- 无色情/性暗示内容
- 无涉政/涉敏感历史事件内容
- 无真实人物肖像（描述中不得出现现实名人姓名）
- 无仿冒品牌/商标

### 视频内容合规

- 无字幕/水印（生成时已通过提示词约束）
- 无版权音乐（BGM 约束）
- 无未成年人的不当展示

---

## 审核输出

```json
{
  "pass": true,
  "issues": [],
  "severity": "none",
  "suggestion": ""
}
```

严重程度：
- `none`：无问题，PASS
- `minor`：轻微问题，可修改后使用
- `major`：重大问题，必须重新生成
- `block`：直接屏蔽，不可用
